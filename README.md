# Seafood Сочи — бот, мини-приложение и админка для Telegram и MAX

Один сервер на Node.js без внешних зависимостей. Он обслуживает:

- **Чат-бот в Telegram и MAX:**
  - каталог по разделам и карточка товара с выбором количества;
  - поиск словом, корзина, оформление заказа в 6 шагов;
  - вопросы менеджеру, статусы заказа, повтор заказа.
- **Мини-приложение «Магазин»** — витрина с фото, поиском, корзиной и формой заказа. Открывается в обоих мессенджерах. Корзина общая с чатом.
- **Админ-панель `/admin`:**
  - товары, цены, наличие, фото, акции с датами, категории, настройки магазина;
  - заказы со сменой статуса.

  Работает с компьютера и с телефона.
- **Уведомления менеджерам в мессенджере** — карточка заказа с кнопками «Подтвердить», «Итог по весу», «Курьер выехал», «Доставлен», «Отменить».
- **Битрикс24** — по желанию: лид или сделка с товарами на каждый заказ.

Каталог живёт в самом приложении: что поменяли в админке, сразу видно в боте и в магазине.

## Как устроено хранение

| Что | Где | В git? |
|---|---|---|
| Код | репозиторий | да |
| Стартовый каталог (109 товаров, загружается при первом запуске) | `data/catalog.seed.json` | да |
| Рабочий каталог, фото, заказы, корзины | `storage/` на сервере | **нет** |
| Токены и пароли | `.env` на сервере | **нет** |

Обновление кода (`git pull`) не трогает каталог и заказы. Раз в день, при первом изменении каталога, его копия сохраняется в `storage/backup/`.

## 2. Сервер

Подойдёт любой VPS в РФ: Ubuntu 22/24, 1 ГБ RAM.

1. Добавьте A-запись домена (например `bot.seafood-sochi.ru`) на IP сервера.
2. Установите Docker, скачайте проект, задайте настройки и запустите:

```bash
curl -fsSL https://get.docker.com | sh

# доступ сервера к приватному репозиторию: deploy key
ssh-keygen -t ed25519 -f ~/.ssh/github -N ""
cat ~/.ssh/github.pub   # → GitHub: Settings репозитория → Deploy keys → Add (только чтение)
printf "Host github.com\n  IdentityFile ~/.ssh/github\n" >> ~/.ssh/config

git clone git@github.com:ВАШ_АККАУНТ/seafood-sochi-bot.git /opt/seafood-bot
cd /opt/seafood-bot
cp .env.example .env && nano .env      # DOMAIN, PUBLIC_URL, ADMIN_PASSWORD, токены, MANAGER_PIN
docker compose up -d --build
docker compose logs -f bot             # должно быть «бот @… запущен»
```

3. Проверьте `https://ваш-домен/health` — должен ответить `{"ok":true,...}`.

### Перенести фото к себе (один раз)

Стартовые товары ссылаются на фото с seafood-sochi.ru. Команда скачает их к вам на сервер:

```bash
docker compose exec bot node scripts/import-images.js
```

Повторный запуск безопасен. Новые фото из админки и так сохраняются на сервере.

## 3. Обновление после изменений в коде

На сервере:

```bash
cd /opt/seafood-bot && git pull && docker compose up -d --build
```

Или одной кнопкой из GitHub: **Actions → «Деплой на сервер» → Run workflow**. Для этого один раз добавьте секреты репозитория (Settings → Secrets → Actions):

- `SSH_HOST` — IP сервера;
- `SSH_USER` — обычно `root`;
- `SSH_KEY` — приватный SSH-ключ, которым можно зайти на сервер;
- `APP_DIR` — `/opt/seafood-bot`.

## 4. Админ-панель

Откройте `https://ваш-домен/admin` и введите пароль `ADMIN_PASSWORD`.

**Товары:**
- цену и наличие можно менять прямо в списке — сохраняется сразу;
- нажатие на название открывает карточку: фото, описание, категория, способ продажи, акция;
- стрелки ▲▼ задают порядок товаров в магазине;
- «Нет в наличии» скрывает товар у покупателей, но не удаляет его.

**Способы продажи:**

| Способ | Как считается | Пример |
|---|---|---|
| Поштучно или упаковкой | цена за 1 шт | икра 250 г |
| На вес | цена за кг; минимум 300 г / 500 г / 1 кг, дальше шаг 500 г | филе, копчёности |
| Целиком, штуками | цена за кг и примерный вес 1 шт; покупатель выбирает штуки | форель, осётр |

**Остальное:**
- **Акция:** цена по акции и даты «с/по». Акция включается и выключается сама по времени Сочи.
- **Категории:** добавить, переименовать, сменить значок, задать порядок. Удалить можно только пустую.
- **Заказы:** активные и все. Смена статуса и «итог по весу» сразу уведомляют покупателя в чате.
- **Настройки:** название, телефон, WhatsApp, часы работы, условия доставки и оплаты, минимальная сумма заказа. «Цены актуальны на» обновляется само при изменении цен.

Защита: пароль, сессия на 30 дней в защищённой cookie, ограничение 10 попыток входа за 15 минут, запросы с чужих сайтов отклоняются. Смена `ADMIN_PASSWORD` выкидывает все открытые сессии.

## 5. Мессенджеры

**Telegram.** Создайте бота в @BotFather: `/newbot`, затем `/setuserpic` и `/setdescription`. Кнопку «Магазин» бот поставит сам.

**MAX.**
1. На платформе для партнёров создайте бота: «Чат-боты» → создать.
2. Откройте ⋮ → Настройки. В поле ссылки на мини-приложение вставьте `https://ваш-домен/app/?p=max`, выберите кнопку «Открыть».

**Менеджеры.** Каждый сотрудник пишет боту `/manager ПИН`, где ПИН берётся из `MANAGER_PIN`. Отключиться: `/manager off`.

После проверки переключите оба бота на вебхуки: в `.env` поставьте `TG_MODE=webhook` и `MAX_MODE=webhook`, затем выполните `docker compose up -d`. MAX рекомендует long polling только для разработки.

## 6. Структура

```
src/
  index.js              запуск
  config.js             настройки из .env
  catalog.js            каталог: хранение, изменение, поиск
  admin.js              API админ-панели и вход
  media.js              фото товаров (/media)
  shared/pricing.js     правила цены и веса — общие для бота, магазина и админки
  bot.js                логика бота — одна для обеих платформ
  orders.js             заказы, уведомления, статусы
  adapters/             Telegram и MAX
  initdata.js           проверка подписи мини-приложения
  server.js             HTTP: магазин, админка, API, вебхуки
  b24.js                Битрикс24
webapp/index.html       мини-приложение
webapp/admin.html       админ-панель
scripts/import-images.js  перенос фото с внешних ссылок на свой сервер
data/catalog.seed.json  стартовый каталог
test/run.js             автотесты (npm test)
```

## 7. Тесты

```bash
npm test
```

Тесты проходят без сети и без токенов. Что проверяется:

- заказ в чате и подтверждение менеджером, вопрос и ответ;
- запросы к API Telegram и MAX;
- мини-приложение: подпись, корзина, минимальная сумма;
- админка: вход и защита, товары, фото, категории, настройки, статусы заказов;
- перенос фото.
